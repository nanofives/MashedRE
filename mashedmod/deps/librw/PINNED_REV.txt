Why a snapshot and not a submodule
----------------------------------
Upstream is actively maintained (last push 2026-07-14 as of snapshot date). We
want a pinned, reproducible renderer, and we expect to carry local patches. This
matches the only other vendored library in the tree (deps\qhull-2002.1, also a
snapshot). The three git submodules under re\prior_art\ are read-only prior art,
a different role.

A pristine upstream clone is kept (gitignored) at:
    re\prior_art\renderware\librw
Diff this snapshot against it to see our local patches:
    git -C re\prior_art\renderware\librw diff 1252b90e -- src rw.h

What was included / excluded
----------------------------
INCLUDED : rw.h, args.h, src\** (all backends: d3d, gl, ps2, lodepng),
           LICENSE, README.md, ARCHITECTURE.MD, TODO,
           premake5.lua + CMakeLists.txt (reference only — we do NOT use them).
EXCLUDED : skeleton\ (3.8 MB GLFW/SDL demo app), tools\ (1.4 MB),
           premake5.exe (1.3 MB binary), Dockerfile, cmake\, .github\, .git\.

We build with a plain cl invocation (deps\librw\build_librw.bat), NOT premake and
NOT CMake. Only src\*.cpp, src\d3d\*.cpp and src\lodepng\*.cpp are compiled
(RW_D3D9). src\gl\ and src\ps2\ are carried for upstream-diff fidelity but are
never compiled.
