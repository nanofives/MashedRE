Mashed RE (development build)
=============================

This is mashed_re.exe, the standalone rebuild of Mashed: Fully Loaded from the reverse-engineering project. It plays
from the game files in original\ and runs none of the original game's code.

Start:   double-click "Mashed (RE)" (made by the updater) or "Play Mashed.bat".
Update:  close the game, then double-click update.bat. Only changed files are downloaded, and game files the
         server no longer ships are removed from original\.
Files the game writes in this folder: videocfg.bin (made on the first run), mashed_re_gamesave.bin, mashed_re.log
         and log\. The updater never touches them. Send mashed_re.log and log\ if something goes wrong.

This is a work-in-progress build of a reconstruction: some screens, effects and sounds are still missing or differ
from the original game.
