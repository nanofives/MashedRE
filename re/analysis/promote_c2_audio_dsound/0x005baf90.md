## Signature

> **Correction 2026-10-12 (negctl re-earn, re-ported from the bytes of MASHED.exe.unpatched; supersedes the text below where they disagree).** The function does not always return 1. It calls slot 8 with TWO stack args, `push &[esp+4]` (the caller's arg slot, still holding param_1) and `push [param_1+0x7c]` (0x005baf94..0x005baf9f), then maps the low byte of that dword (0x005bafa2..0x005bafb1) through the jump table at 0x005bafdc: 1->3, 2->2, 3->1, 4->1, 5->4, 6->5, 7->6, any other byte -> 1 (0x005bafd6). Body is 0x005baf90..0x005bafdb.


```c
undefined4 FUN_005baf90(int param_1);
// __cdecl (inferred); param_1 = audio buffer object pointer.
// Calls vtable slot 8 (offset 0x20 / 4 = slot 8) on the IDirectSound8* at param_1+0x7c.
// Discards return value; always returns 1.
```

## Why C2

1. `**(int **)(param_1 + 0x7c)` — dereference: param_1+0x7c holds IDirectSound8*; dereference gives vtable pointer.
2. `(*(code **)(vtable + 0x20))(*(int **)(param_1 + 0x7c))` — calls method at vtable offset 0x20 (slot 8) with the IDirectSound8* as the implicit this-pointer.
3. IDirectSound8 vtable (0-indexed): slot 8 = GetSpeakerConfig at offset 0x20 [UNCERTAIN U-0361].
4. Return value of the vtable call is discarded; Ghidra confirms no use.
5. `return 1` — unconditional; function body is ~0x18 bytes (0x005baf90–0x005bafdb; the extra span includes a Ghidra switch-case artifact note).
