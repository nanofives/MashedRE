## Semantics (C3, 2026-09-03)

**This is the standings LEADER-CROWN gate.** The 4-DWORD mask it writes is the crown
flag array `DAT_0063cde8`, and a set entry becomes bit `0x40` of a standings row
group's enable word, which is what makes the `NewPanelCrown` sprite draw and pulse.

    for (i = 0; i < 4; ++i)
        DAT_0063cde8[i] = (DAT_008a94e0[i] >= FUN_0040b8e0()) ? 1 : 0;

So the crown is **not** "the leader" -- it marks every car whose score has reached the
WIN THRESHOLD returned by `FUN_0040b8e0` @`0x0040b8e0` (7 when the race rule
`DAT_007f0fd0` is 1 or 2, when `DAT_0067ea64` != 0 via `FUN_0042f500` @`0x0042f500`, or
with fewer than 4 participants via `FUN_0040e340`; otherwise 10). Those arms coincide
with the score-bar max from `FUN_0040b890` @`0x0040b890`: `max = threshold + 2`.

Live call chain: `FUN_0041cc50` @`0x0041cc50` (per-frame standings update) passes
`&DAT_0063cde8` here, then dispatches `FUN_0041c410` @`0x0041c410` per row, which reads
the flag into the enable word. The rule **predicts the reference capture**:
`verify/race_hud/orig_stand7.bmp` has scores 8/7/5/4 against a 4-player threshold of
10, so no row is flagged -- which is why no original capture has ever shown a crown.

`DAT_0067ea64`'s meaning is unresolved: `[UNCERTAIN U-9078]`.
