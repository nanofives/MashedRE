## Mechanical description

Computes the byte size of a replay buffer from the frame count:

- Calls `__ftol` (`FUN_004a2c48`) at `0x0048290f` — NOT 0x00482904, which is `PUSH ESI`.
  It does NOT return a frame count: it converts the x87 ST0 value built by
  `FLD [ESP+4]` / `FMUL 60.0f` / `FIDIV [ESP+0xc]` into an integer. The argument
  is in ST0 and is invisible to the decompiler, which is why this reads as a
  zero-argument call. CORRECTED 2026-07-31 (orchestrator iter17).
- Computes `iVar1 = iVar1 * 0x24 + 0x19c` at `0x00482909`, `0x0048290f`.
- Calls `FUN_004987b0("Replay size is %d\n", iVar1)` at `0x00482918` — debug print (printf-family).
- Returns `iVar1` at `0x0048292a`.

## Formula

`size = frame_count * 36 + 412`

- `0x24` (36) = per-frame record size in bytes.
- `0x19c` (412) = fixed header size.
