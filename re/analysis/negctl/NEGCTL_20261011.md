# Negative controls for the Frida A/B handlers (2026-10-11)

Plan item #6 (approved 2026-10-11). Port of SimGolf's negative-control discipline
(`SimGolf/shim/src/re/*_negctl.cpp`), made generic: a deliberately wrong port must read RED.
A handler (arg_type + registry entry) that stays GREEN under a wrong port is BLIND to that
defect class, and the C3/C4 rows whose evidence rests on it are at risk.

**No row was demoted.** Demotion is the user's call. The at-risk list is
`atrisk_20261011.tsv`.

## Tooling

| piece | what it does |
|---|---|
| `mashedmod/src/mashed_re/Harness/NegCtl.cpp` | Dev `.asi` only (`asi_sources.rsp`; `#error` under `MASHED_STANDALONE`), armed only with `MASHED_NEGCTL=1`. One naked forwarder wraps the REAL port and breaks it one way per run. |
| `re/frida/run_negctl.py` | For every registry entry backing a C3/C4 row: `real`, `baseline` (`--self-baseline`) and the mutant classes. Warm pool (diff_template handlers), early lane (early-window-only handlers), `--race` lane, live TSV + `--resume`. |
| `re/frida/negctl_report.py` | Per-handler table + at-risk rows, with a stored-evidence triviality check and census-scoped heap/import exposure. |
| `run_diff.py --negctl <class>`, `early_window_leaf_diff.py --negctl/--self-baseline` | Single-hook entry points. `run_verify_hook.py` refuses both flags: path2 checks installation, never values. |

Mutant classes (`NegCtl_Arm`):

| class | wrong port |
|---|---|
| `null` | port never called; EAX = 0 (ST0 = 0.0 for a float return) |
| `ret` | `ret_int` EAX ^= 1, `ret_float` ST0 = ST0*2 + 0.75; SKIP on a void signature |
| `field_first` / `field_last` | XOR 0x5A into the first / last byte the port changed: arg windows (stack args 0..7, ECX EAX EDX ESI EDI EBX, 0x400 bytes each), then MASHED.exe `.data`/`_rwdseg` minus a calibrated noise mask. Every thread whose Win32 start address is inside MASHED.exe is suspended for the snapshot..diff span. NA when the port changed no visible byte. |
| `field_none` | CONTROL for the two above: same freeze/snapshot/diff, no flip. CTRL-RED marks a vector that the freeze latency alone perturbs; that hook's field verdicts are discarded. |
| `heap_extra` | one extra game-CRT `_malloc(0x20)` (0x004a45fb), leaked. Run only where `re/coverage/standin_census_d2.tsv` lists a heap call within depth 2. |
| `import_extra` | one extra `kernel32!GetTickCount` through the `.asi` IAT. Census-scoped the same way. |

Verdicts: RED (detected), BLIND (GREEN under the mutant), BLIND-DEGENERATE (all observations
trivial on both sides), NA, SKIP, ERROR. A mutant verdict is held against a row only when the
row's `real` run is GREEN, or when it is DEGENERATE **and** the row's stored path1 CSV
(`frida_diff` column, main checkout `log/`) is all-trivial too.

## Coverage

25 handlers (the top 15 by C3/C4 rows x risk, plus ranks 16-25), 665 registry entries, 5,430
jobs (`negctl_jobs_20261011.tsv`). Per-handler table: `table_20261011.md`.

Not covered:
- 51 `scenario='race'` entries (47 C3, 4 C4; `race_uncovered_20261011.txt`).
  `run_diff.drive_to_race` times out at the menu (`[nav] timeout: d3 depth=2 phase=3`) in plain
  `run_diff.py` too, so the scenario lane is broken independently of this work.
- 8 C3/C4 entries name an export the current `.asi` does not have (`missing_exports_20261011.tsv`).

## Results: what each handler can see

- Every handler reads RED on `null` for at least part of its rows except where noted below.
  The baseline (original vs original) is GREEN wherever `real` is GREEN.
- **`none` / `int_scalar` / `void` / `int_pair`** observe only the return. In the warm lane,
  79/128 `none`, 81/110 `int_scalar`, 7/11 `void` and 8/23 `int_pair` real runs are DEGENERATE (every
  observation trivial on both sides), and `null` reads BLIND-DEGENERATE on them.
- **`read_global`**: RED on null/ret for 92/93 rows. Field classes are NA on getters (they write nothing).
- **`void_setter_observe`**: BLIND on `null` for 37/40 rows before the fix below (the reimpl
  arm read the original arm's write). After the fix: null RED 39/40.
- **`entity_field_set`**: BLIND on `null` 8/8 before the fix (DEC-6). After: RED 8/8, real and baseline GREEN 8/8.
- **`scalars_to_scattered_globals`**: 10 rows RED on real AND baseline ("bad argument count"),
  9 more BLIND on null (zero-byte observe windows). After the two fixes: real GREEN 30/31,
  null RED 27, BLIND 4 (clears whose observed globals are already zero; their fixtures need
  `pre_fill_byte`).
- **`standin_object_call`**: the only handler that reads `heap_extra` RED (15/15). Every
  value-only handler is blind to an extra heap or import call by construction.
- **`void_write_observe`**: null BLIND on 4 (the fixtures never reach the write).
- **`ptr_arg_int_get`**: field BLIND on 6/8 (it observes the return only; the port writes the shared buffer).
- **`draw_quad_observe`**: 5/11 CTRL-RED (VBUF is rewritten by the running game), so its field verdicts are void on those.

Group A notes:

## Harness fixes made (all in this branch)

1. `void_setter_observe`, `entity_field_set`: per-side sentinel (~value pre-written before each
   arm; `entity_field_set` restores the slot). This is DEC-6, which was funded and never built.
2. `scalars_to_scattered_globals`: args trimmed to the declared arity; `observe` window `len`
   defaults to 4 (it was 0).
3. `self_baseline` also rebinds `reimplAddr`: the 8 register-trampoline handlers'
   "baseline" used to call the port.
4. `standins.js`: the `observe_ret_len` read is guarded, so a wrong returned pointer reads RED
   (`retmem=AV`) instead of aborting the fixture.

## Defects found, not fixed

- `diff_template.js` generic stand-in wrapper (`heap_standin`/`import_standin` on a handler other
  than `standin_object_call`) assigns `globalThis.send`, which is non-writable and
  non-configurable under `'use strict'` (tested). It throws on install. No registry entry uses it today.
- `run_diff.drive_to_race` fails at the menu (see Coverage).
- Intermittent "freeze: thread already suspended" from the stand-in `freeze_main`
  (3 occurrences in one warm run, not reproducible on demand; the runner retries once).

## Caveats

- Warm lane = booted menu state. A row verified in another state can read DEGENERATE here. The
  stored-evidence check keeps those (stored CSV non-trivial) out of the at-risk list.
- `field_*` BLIND rows list the flipped address (`field_flip` column). A few
  `0x007d70cc..0x007d70d8` flips survive the freeze (1-3 of 10 calls); treat a field BLIND whose
  flips are intermittent as unconfirmed.
- Independent-evidence tags are keyword matches; confirm before acting on one.

`Harness/NegCtl.cpp`), then `py -3.12 re/frida/negctl_report.py <live tsv...>`.
