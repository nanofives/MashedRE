## Mechanical description

Setter companion to FUN_0046cbb0 (vehicle spinout-state getter, C2).

```c
if (param_1 > 0xf) return 0    // OOB guard
DAT_00881f90[param_1 * 0x341]              = param_2   // spinout state
*(uint32*)(DAT_00881f94 + param_1 * 0xd04) = param_3   // secondary state/timer
return 1
```

- `param_1` = vehicle/player index (0–15).
- `param_2` = spinout state (0=alive, 2=slide, 0xff=expired per callers).
- `param_3` = secondary state value (timer or secondary flag).
- `DAT_00881f90` = per-vehicle state array, stride 0x341 (same as FUN_0046cbb0 read side).
- `DAT_00881f94` = secondary per-vehicle state, stride 0xd04 (same as FUN_0046cbb0 read side).

## Correction 2026-10-12 (reearn/fstate, from the bytes)

- The guard is UNSIGNED: 0x0046cbe4 `cmp eax,0x10` ; 0x0046cbe7 `jb` (idx >= 0x10 -> return 0).
  `param_1 > 0xf` above must be read as an unsigned compare.
- Both stores are DWORDs at the same 0xd04-byte stride (0x0046cbf0 `imul eax,eax,0xd04`):
  0x0046cbfa `mov [eax+0x881f90],ecx`, 0x0046cc00 `mov [eax+0x881f94],edx`. The old port
  stored a single BYTE at 0x00881f90 (Vehicle/SmallLeaves_o5.cpp).
- A second implementation (Vehicle/Physics.cpp VehicleSpinoutStateSet) registered first and was
  the copy installed in the .asi while run_diff measured VehicleCarStateSet. It was removed; the
  single body is VehicleCarStateSet in Vehicle/SmallLeaves_o5.cpp.
