## CORRECTION 2026-09-11 — name was wrong, and the caller list was wrong

This plate proposed `RwResourcesEmptyArena_PopSlot`. **That name is incorrect.** The function touches no
arena and no resource list. It is `RwErrorGet`.

`RwError *RwErrorGet(RwError *code)` — `rwplcore.h:6129`. `struct RwError` is
`{ RwInt32 pluginID; RwInt32 errorCode; }` — two dwords — at `rwplcore.h:6100`.

- `0x004d84f0`/`0x004d84f3` copy `pluginID` into `param_1[0]`.
- `0x004d84fb`/`0x004d84ff` copy `errorCode` into `param_1[1]`.
- `0x004d850e` resets the live `pluginID` to `0`.
- `0x004d8521` resets the live `errorCode` to `0x80000000`, which is
  **`E_RW_NOERROR`** (`rwplcore.h:6112`, "common errors have the MSB set").
- Returns `param_1` (EAX still holds it from `0x004d84ec`), matching the
  declared `RwError *` return.

Retrieve-and-clear is exactly the documented contract of `RwErrorGet`.
