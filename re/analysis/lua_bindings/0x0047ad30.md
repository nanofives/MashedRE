# 0x0047ad30 — COURSE.LUA dirt-texture binding (NO-OP STUB)

**Confidence C2** (decomp read end-to-end; 16 bytes, every instruction cited).
Registered under TWO script names. Resolves U-9041.

## Registration

`RegisterScriptCommand` (0x0047b980) is called twice with the SAME function pointer:

| site | pushes | name string | name |
|---|---|---|---|
| `0x00440d6d` | `push 0x47ad30` / `push 0x5cddfc` | `0x005cddfc` | `Vehicle_Body_Dirt_Texture` |
| `0x00440d7c` | `push 0x47ad30` / `push 0x5cdde0` | `0x005cdde0` | `Vehicle_Wheel_Dirt_Texture` |

The two sites are byte-identical apart from the name pointer. There is **no index, no
extra argument and no discriminator of any kind** passed at registration.

## Body — complete, 0x0047ad30..0x0047ad3f (16 bytes)

```asm
0x0047ad30  8b 44 24 04    mov  eax, [esp+4]      ; param_1 = lua_State*
0x0047ad34  50             push eax
0x0047ad35  e8 86 c2 03 00 call 0x004b6fc0        ; lua_gettop(L)
0x0047ad3a  83 c4 04       add  esp, 4            ; cdecl cleanup
0x0047ad3d  33 c0          xor  eax, eax          ; return 0
0x0047ad3f  c3             ret
```

Shape: `int __cdecl f(lua_State* L)`. One argument, forwarded verbatim to one callee.
**The callee's return value is discarded** — nothing consumes `eax` between `add esp,4`
and `xor eax,eax`. Returns 0, the `lua_CFunction` convention for "zero return values".

Ends at `0x0047ad3f`; `SetClumpAnim` begins at `0x0047ad40`.

## The callee is lua_gettop

`0x004b6fc0` (already tracked C2, subsystem `third-party-library[lua-5.0]`) is:

```c
return *param_1 - param_1[4] >> 4;
```

A pointer difference at `L+0x00` minus `L+0x10`, divided by 16 — i.e.
`(L->top - L->base) / sizeof(TObject)`, which is `lua_gettop`. Corroborated by its 44
callers: nearly every COURSE.LUA binding handler calls it first, the standard way a
`lua_CFunction` reads its argument count.

## U-9041 RESOLVED — it does not discriminate, because it does nothing

The uncertainty asked how one handler distinguishes body from wheel. **It cannot, and it
does not need to.** The function reads its argument count and throws it away. It never
touches the Lua stack values, never writes memory, and returns no values. Both script
names are accepted by COURSE.LUA and **silently ignored**.

Ghidra has no function at this address, so this was undiscovered code.

## Consequence for the port

`Vehicle_Body_Dirt_Texture` and `Vehicle_Wheel_Dirt_Texture` in COURSE.LUA have **no
effect in the original**. Any reimplementation must also do nothing; giving them behaviour
would diverge from the original. The dirt-texture data, if applied at all, is applied
somewhere else — [UNCERTAIN] where, and this note does not speculate.
