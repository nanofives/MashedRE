## Semantics (C3, 2026-09-03)

**This is the STANDINGS ROW ORDER.** It writes `out[row] = the player index ranked at
that row`, so row 0 is the highest scorer. The live caller `FUN_0041cc50` @`0x0041cc50`
passes `&DAT_0063cdf8`, and `FUN_0041c410` @`0x0041c410` finds a standings group's
screen row by searching that array for the group's own player index (`group+0x108`),
then places the row from `DAT_005f337c[row]`.

    for (i = 0; i < 4; ++i) {
        local[i] = DAT_008a94e0[i];                    // per-car score
        if (DAT_007f1a14[i * 4] == -1) local[i] = -100; // absent slot -> sinks
        out[i] = i;
    }
    // 3 passes of adjacent-swap bubble sort, DESCENDING on local[], carrying out[]
    if (DAT_007f0fd0 == 4 || DAT_007f0fd0 == 7) for (i) out[i] = FUN_00417740(i);
    if (DAT_007f0fd0 == 9) out[0..1] = DAT_007f0fcc ? {0,1} : {1,0};

Comparison is strict `<` with no tiebreaker, so equal scores keep their original
relative order across the three passes (confirmed empirically, vector 2 below).

**U-0490 RESOLVED by this promotion** (that row's `Blocks` cell asked for exactly this):

- `DAT_008a94e0` is the **per-car score array**, 4 int32. Same array
  `FUN_0040b6d0` @`0x0040b6d0` indexes to return a car's score, and the array the
  score-bar cell count and the crown threshold both read (Findings 18/19/20).
- `DAT_007f1a14` is the **per-slot record base**, and the stride is **0x10 bytes, not
  4**. `piVar7` is an `int*` advanced by `+ 4` (= 16 bytes) with the loop bound
  `(int)piVar7 < 0x7f1a54`, i.e. `0x007f1a14 + 4*0x10` exactly. Corroborated
  independently: the per-car Player Colour that Finding 16 bound is `DAT_007f1a1c`
  = `0x007f1a14 + 8`, inside record 0 of the same table. Field `+0` is the
  **active/absent sentinel**, `-1` meaning the slot holds no player.

## Mechanical description

- Takes one parameter: `undefined4 *param_1` — output array of 4 ints.
- Initialization loop (4 iterations via `piVar7` from `DAT_007f1a14` to 0x007f1a54, stride 4 words):
  - Copies `(&DAT_008a94e0)[i]` into `local_10[i]`.
  - If `*piVar7 == -1`, overwrites `local_10[i] = -100`.
  - Sets `param_1[i] = i` (identity index mapping).
- Bubble sort (3-pass, descending) on `local_10[0..3]`, swapping `param_1` entries in parallel to track original indices.
- If `DAT_007f0fd0 == 4` or `DAT_007f0fd0 == 7`: overwrites all four `param_1` entries with `FUN_00417740(0)` through `FUN_00417740(3)` (replaces sort result).
- If `DAT_007f0fd0 == 9`:
  - If `DAT_007f0fcc != 0`: writes `param_1 = {0, 1}`, returns.
  - Else: writes `param_1 = {1, 0}`, returns.
