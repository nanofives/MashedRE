# FUN_005baf90 — IDirectSound8 vtable+0x20 caller (maps the out byte through 0x005bafdc)

> **Correction 2026-10-12 (negctl re-earn, re-ported from the bytes of MASHED.exe.unpatched; supersedes the text below where they disagree).** The function does not always return 1. It calls slot 8 with TWO stack args, `push &[esp+4]` (the caller's arg slot, still holding param_1) and `push [param_1+0x7c]` (0x005baf94..0x005baf9f), then maps the low byte of that dword (0x005bafa2..0x005bafb1) through the jump table at 0x005bafdc: 1->3, 2->2, 3->1, 4->1, 5->4, 6->5, 7->6, any other byte -> 1 (0x005bafd6). Body is 0x005baf90..0x005bafdb.

RVA: 0x005baf90  Size: ~0x18 bytes  Session: audio_dsound_d4  Clears: (depth-1 callee of D-0940 tail)

## Mechanical description
1. Reads `param_1[+0x7c]` as a pointer to an IDirectSound8* (or compatible COM object)
   - Same field accessed in d3 analysis (e.g., FUN_005baa60 used +0x7c for IDirectSound8*)
2. Dereferences the vtable at offset `+0x20` (slot 8 = 0x20/4): calls vtable method 8 on the object
   - On IDirectSound8, vtable+0x20 = `GetSpeakerConfig` [UNCERTAIN U-0361]
   - Alternatively: `SetSpeakerConfig` is at vtable+0x24; `Compact` at vtable+0x28
3. Return value of vtable call is discarded; function unconditionally returns 1.
