Port of SimGolf `re/frida/js/{heapstandin,importstandin,freeze}.js` into `re/frida/js/standins.js`.

## Step 0: census (static, `re/tools/standin_census.py`)

The tool walks each hooks.csv row's direct-call tree in `MASHED.exe.unpatched` (capstone) and records the first depth
at which it reaches CRT alloc/free (`_malloc` 0x004a45fb, `__nh_malloc` 0x004a45cf, `_calloc` 0x004a467e, `_free`
0x004a460d, plus 3 alloc and 2 free CRT-band thunks found by shape), a RwGlobals memory slot (`call [reg+0x108..0x11c]`
with reg loaded from `[0x007d3ff8]`), the RW file block (+0xd8..+0x104), or an IAT import. Output:
`re/coverage/standin_census_d1.tsv` (root body + direct callees) and `_d2.tsv`. Crossed with `re/coverage/reach.tsv`.

The 59 split render 22, vehicle 7, gameplay 7, boot 6, track 4, particle 4, physics 3, util 2, audio/frontend/hud/sky 1
each; 39 are menu-reached, 20 race-only. The 167 - 59 = 108 difference is rows the tracker labels first-party
(`render`, `audio`, `hud`, `util`, `boot`) that sit inside address ranges holding RenderWare core (0x004c0700..0x004dc300,
e.g. `RwEngineInit` 0x004c32b0, `RwFreeListDestroy` 0x004cc9f0), the libpng band (`png_create_struct_2` 0x005207c0,
labelled `util`), the 0x004f0810..0x004f46a0 run between d3dx9-psgp bands, the 0x005a5820..0x005c0000 audio run and the
0x005c0000..0x005c8000 CRT tail (labelled `boot`). **Those labels are a library-vs-first-party question for Mariano**;
the promotion rounds here stay inside the game-code zone.

Of the 72 orchestrator gate rows with a TEARDOWN / WRITES_GLOBAL / CALLS_UNKNOWN safety verdict
(`re/orchestrator/gate_ranked.tsv`), 31 are reached first-party C2, 10 of them touch alloc/free/import within 2 levels,
5 inside the 218: 0x00494460 TEARDOWN, 0x00494a80 / 0x00556d20 / 0x0048bbe0 WRITES_GLOBAL, 0x00491780 CALLS_UNKNOWN.

Caveat: the census counts rows whose blocker the stand-ins REMOVE. 57 of the 59 have no port yet, so each still needs one.

## Step 1: harness

- `re/frida/js/standins.js`: one install per run, `arm()` / `disarm()` around each A/B arm. Patched entries jump to a
  native stub gated on the A/B thread id AND an `armed` dword, so the game's threads never enter JS (hot-path rule) and
  the fixture's own allocations while disarmed reach the real allocator. CRT entries via `Interceptor.replaceFast`;
  RwGlobals slots (+0x108 rwmalloc, +0x10c rwfree, +0x110 rwrealloc, +0x114 rwcalloc, +0x118 RwFreeListAlloc, +0x11c
  RwFreeListFree; arities 2/1/3/3/2/2 confirmed from every call site's `add esp`) and IAT slots of MASHED.exe and the
  loaded .asi by dword swap. Allocations carve one arena reset per arm (same addresses both arms; `failMask` /
  `failSize` schedule NULL returns), frees are recorded with their entry tag, imports return the fixture value and are
  recorded with their arguments. `__freeze` (main-thread safe-point suspend) is ported but opt-in (`freeze_main`) and
  not yet exercised by any entry.
- `diff_template.js`: `self_baseline` (`run_diff.py --self-baseline` binds the reimpl arm to the original), arg_type
  `standin_object_call` (game-heap fixture object reused by both arms), and a generic wrapper that arms the stand-ins
  around any handler's Orig/Reimpl calls and appends per-call log rows `S<k>`.
- CONFIG keys `heap_standin`, `import_standin`, `freeze_main`, `object_size`, `object_alloc` forwarded by
  `run_diff.build_config` AND `run_verify_hook.py` (`STANDIN_KEYS`); every agent builder (`run_diff`, `_warm`,
  `_scenario`, `_scenario_batch`, `run_verify_hook`) prepends the library via `run_diff.agent_source`.
- Port rule the import stand-in enforces: a port body must not call .asi CRT functions that lock (getenv, printf):
  the .asi IAT is stood in too, so the CRT lock pair is recorded as extra imports and reads RED.
