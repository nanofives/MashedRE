- `_ftol2` at `0x004a2c48` truncates toward zero (FISTP + correction), the same as the port's `Ftol`

- `FUN_00472650` (`0x00472650..0x00472682`): `u = FUN_00534870()`, `(u & 0x7fffffff)` FILD,
  x `[0x005cd314]` = `0x30000000` (2^-31), x `(hi - lo)`, + `lo`. `FUN_00534870` is the RW additive
  ring, already ported verbatim as `RwRandomNext` (`AiStandalone.cpp:662`).
- `0x005f2d80` rows 0..10: (0,3) (1,4) (1,5) (2,6) (3,7) (4,8) (5,9) (6,10) (7,10) (8,10) (9,10);

**(1, 5)**. Original: `flt360 = 2.5` on every sampled row of `o_leg1b.csv` -> also idx 2, row (1,5).

### 1.5 G-EXIT law, re-derived

`LaunchRevCharge.cpp:137-160` (0x0046d7f0): a pressed frame does +100 - 50 = +50, an unpressed one
-50 floored at 0. Branch A (`AiStandalone.cpp:1762-1770`) presses while `elapsed < (cd + 0x40)*100`
with `elapsed = 12000 - 50j`, so it presses on j = 113-2cd..112, which is **2·cd frames**, giving
charge **100·cd**. Release (`:217-226`, 0x0046d780): charge in (0, 1000] gives `+0xbf4 = c + 1000`,
`+0xbf8 = 1`. So **G-EXIT(v) = 1000 + 100·cd(v) / 1** for AI cars. The player (v=0) is not driven by
Branch A: 0 / 0 (as in `L1B_M5CD`).
