## 2. Why 764 and not 652

The entry dynamics are exact (path1 GREEN, G-TRANSCRIBE). The offline model reproduces the original
too: fed the original's own target it releases at frame 650, against 651 recorded (`PREREG §1.1`).
So the length difference comes from what entry 0 chases, the camera position. The port's starts at
(0.030, 3.304, 4.838) and drifts to (0.453, 3.046, 4.526). The original's goes from (-0.149, 3.542,
4.455) to (-0.077, 2.986, 5.243). Named contributors, not separated (U-9201):
- the original runs the camera through states 0-2, while the port starts it at phase 3, with a first
  call that reads (0,0,0);
- `FUN_00442a20` (the main block's flag != 0 call) is not in `RaceCamera`;
- the first two chain calls run at dt = 0, because the state-2 tail frame does not run `FUN_0040fc00`
  (a leg-1b choice).
