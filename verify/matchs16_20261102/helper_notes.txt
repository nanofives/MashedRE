Techniques that worked in this slice:
- __thiscall without C++: `__fastcall f(T *self, int edx_unused, <stack args>)` gives the same entry and `ret N`
  (0x00494ac0, 0x00494c60). For a CALL to a thiscall callee where EDX holds nothing useful, declare the callee's
  stack args as `float` / 4-byte struct types: __fastcall only puts DWORD-or-smaller integer args in EDX, so
  nothing is loaded into EDX and the pushes match (0x00494c80: `push 0` from `0.0f`, `push &hr` from a
  struct {int *p}).
- 0x00494b65 is a mid-function label: the real entry is 0x00494b50 (99 B), file holds FUN_00494b50,
  byte-identical, but 0x00494b50 has no row in re/console/pc_funcs.csv so match.py refuses it ("no Ghidra size").
- `pow` as a name makes 9176 use the _CIpow intrinsic: call the CRT entry as FUN_004a2d30.
- switch with an explicit `case 0:` (own body) next to `default:` keeps the table based at 0 (0x00495150).
- C++ EH functions (0x00494820, 0x004944c0): match.py C++ mode with /EHs and an inline-destructor smart pointer
  emits the EH prologue (scratch/h1/x2_full.cpp.c, 44.3%), but that needs FLAGS/LANG outside the required
  form and the preamble's C++ MGLOBAL references do not compile under the DDK (`&` on constant).
