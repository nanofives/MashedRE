# PREREG D4-WSB-C4-BROAD-A: racediff C4 for 0x0055abb0, 0x0055bb70, 0x0055c230, 0x0055deb0, 0x0055e050

Committed alone, before any arm. No source, default or tracker change on this branch before the arms. Exe and
`.asi` built from `orch/integration` @ `2d75d00d1` (`MASHED_NO_DEPLOY=1`).

## Legs

C4 per row (scope note `verify/wsbc4scope_20261027/RESULT_D4-WSB-C4-SCOPE.md`, group BROAD-A, out-memory leg A):

- **Leg A (static, done):** no store outside the row's own frame (scope note BROAD table, all 5 rows `out = 0`).
- **Racediff:** `c4_racediff_v8.py` (generated by `make_tool3.py` from the BVH-FU v7 tool), one hook installed per
  ON boot (`MASHED_HOOK_ONLY=0x<rva>`), OFF = `__none__` with the `.asi` loaded. Verdict `C4-CLEAN` = OFF and ON
  sample sets equal and non-empty, ON byte at the RVA `0xE9`. Quick Battle window first (A4 calls 300-1200).
  Census scenario (`C4_SCENARIO=census`, track 0, mode 10, 4 cars) for a row the Quick Battle window does not
  observe.

A row is promoted (re-classify, C3 -> C4) only on a `C4-CLEAN` racediff. Any other outcome keeps it C3 and the RESULT
states why. One re-run is allowed for a run with no samples on both sides (harness empty) or a U-9677 piz-collision
crash. A `BEHAVIOR-DIFF` is not re-run to get a different answer: it is reported with the differing signatures.

## 0x0055deb0 (register-ABI row)

The hook jumps to the naked shim `RwpWorldSolverHandle_RegAbi` (`RwpIntegrator.cpp:188`), which calls the C body
`RwpWorldSolverHandle`. v7 keys the port's own body on the `FUN_<rva>` symbol tag, which neither name carries. v8
options for this row only:

- `C4_OWN_SYMS=0055deb0:_RwpWorldSolverHandle` (the shim is the ON entry already).
- `C4_TRANSP_SYMS=b5cselftestenabled` (cached `GetEnvironmentVariableA` read, `RwpIntegrator.cpp:48-53`; no game
  memory read or written). `__security_check_cookie` is transparent in v7 already.
- `C4_REGS=0055deb0`: each sample also records whether ECX and EDX at return equal their values at entry. The
  original (`0x0055deb0..0x0055deb7`: `mov eax,[esp+4]` / `mov eax,[eax+4]` / `ret`) writes neither, so the OFF
  side records `ecx=kept edx=kept`. The ON side must record the same for `C4-CLEAN`.

EFLAGS are not captured (U-9026 stays open, the RESULT says so). Expected ON call-outs: none, the same as OFF.
