## What is swapped

The closed-set tool (`re/tools/port_closed_sets.py`) lists, per subsystem, the sets of C4-by-match rows whose every
callee is in the set, bound to an exe name, or RW core bound to librw (L-98). A set is **lint-clean** when none of its
members has another body in either target (no DUP-IN-TARGET, no CROSS-TARGET, not allowlisted, no matched file that
also holds an already-compiled body), no member reads the RwGlobals pointer `DAT_007d3ff8` (0 in the exe pad), and no
member reads a nonzero file-backed address the L-99 seed does not hold. Only lint-clean sets can sit behind a
default-OFF runtime switch: an in-place swap of a hand body needs the hand body and the matched body side by side
while the switch is OFF, which is a second exe body for the RVA.

Largest lint-clean set the default exe path reaches: **hud, 4 rows** (the only subsystem with one; vehicle has 1, every
other subsystem 0 on the default path).

## Decision rules

- OFF differs from the refs: the change is broken, fix it before anything else (no flip question).
- ON equals OFF: report the flip proposal (MASHED_BATCH_HUD default ON) as a decision, hashes unchanged.
- ON differs: `re/tools/port_batch_bisect.py` splits the heads in halves to single heads, excludes the responsible ones,
  and re-gates the rest ON. The excluded heads go to the RESULT with their ON hashes as flip candidates.
- A crash or a hang with the switch ON is a finding (no re-run rule), unless it is a U-9677 piz collision signature.
